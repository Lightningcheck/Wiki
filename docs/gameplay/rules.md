# Rules

## Explanation 
This page is a summarization of the full rules and focuses on rules relevant to ranked. See [mc.sr/rules](https://mc.sr/rules) for the Official Rule Document.

## Allowed Launchers
- [Prism Launcher](https://mcsrranked.com/download) (recommended)
- [MultiMC](https://mcsrranked.com/download)
- [MCSR Launcher](https://mcsrlauncher.github.io/) (beta)
- [Modrinth App](https://modrinth.com/app)
- [ATLauncher](https://atlauncher.com/)
- [Official Minecraft Launcher](https://www.minecraft.net/en-us/download) (heavily discouraged)

## Rebind Rules
- Rebinding keys is legal, but
  - Each game input may only have 1 key
  - Each key may only cause 1 game input
  - Keys must be rebound to buttons (e.g. binding to scrollwheel is not allowed)
- Left/right click must not be bound to a keyboard button to abuse repeated inputs

## Macro Rules
- Macros may resize the game window to any resolution as long as the game window stays within monitor bounds
- Macros may resize the game to 1 resolution outside monitor bounds (max. 16384 pixels in width or height)
